# 周易书籍整理项目

## 概述
- 用户要把《周易》中华书局2010版 PDF 内容整理成「书籍」目录下的可阅读 Markdown
- PDF 是扫描版（无文字层），OCR 质量差，改用网络抓取

## 数据源
- 64卦经文原文+译文：国学网 `guoxuecn.cloud`（`.content`=原文, `.fanyi`=译文）
- 十翼传文：维基文库 API（注意系辞/说卦/序卦/杂卦重定向到 `易傳/` 页面）

## 产出（已完成 2026-07-08）
- `书籍/周易/周易.md` 完整合一版
- `书籍/周易/周易_上经.md` / `周易_下经.md` 分卷
- `书籍/周易/原文/` 64个卦分文件
- `书籍/周易/十翼/` 9篇传文

## 已知问题
- 简繁混用（维基文库繁体 + 国学网简体），已用 opencc 统一转简体（2026-07-08）
- 译文来自网络版（义理派），非中华书局原书注释（郭彧象数派解读）

## 尝试补充郭彧象数派注释（已放弃）
- 用户曾要求补充原书象数派注释，后因 OCR 质量放弃（选方案3）
- 失败原因：扫描PDF，注释是密集小字，EasyOCR 对卦象符号（震/兑/巽/坎/离/艮/坤）混淆严重
- 教训：象数派核心依赖卦象逻辑，OCR 错字会直接误导，不宜用 OCR 补这类内容
- EasyOCR 自动定位卦起始页也不可靠（正文引用的卦名会干扰判定），不要再用此法
