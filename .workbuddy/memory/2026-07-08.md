## 周易书籍整理项目
- 源文件：`C:/Users/56556/Downloads/ZHSJBYJ_itmop.com/《周易》中华书局2010.pdf`（扫描版，358页，无文字层）
- 用户需求：把 PDF 内容放到「书籍」目录做成可阅读 Markdown（像思维模型那样分章节）

### 技术方案（关键决策）
1. **OCR 路线被否**：PDF 是扫描版，PaddleOCR v3.7 + PaddlePaddle v3.3.1 在 Windows 有 oneDNN 兼容 bug；EasyOCR 能跑但密集注释段乱码严重（如 `湿:^岌1圣`）
2. **改为网络抓取高质量文本**（用户选方案A：原文+注释+译文）：
   - 64卦经文原文+译文：`guoxuecn.cloud`（国学网），用 requests+BeautifulSoup 抓 `.content`(原文) 和 `.fanyi`(译文) 两个 div
   - 十翼传文（彖/大象/小象/文言/繫辭上/繫辭下/說卦/序卦/雜卦）：维基文库 API `zh.wikisource.org/w/api.php` 抓子页面，注意系辞/说卦/序卦/杂卦重定向到 `易傳/XXX` 页面

### 产出文件
- `书籍/周易/原文/01_乾卦.md` ~ `64_未济卦.md`（64个卦，含原文+译文）
- `书籍/周易/维基文库/传文_*.md`（9篇十翼）
- `书籍/周易/十翼/` （复制的传文）
- `书籍/周易/周易.md`（完整合一版，~154KB）
- `书籍/周易/周易_上经.md` / `周易_下经.md`（分卷）

### 注意事项
- 国学网有 429 限流，需要 sleep(1s) + 重试
- 维基文库 API 也有 429，需加重试逻辑
- OpenCV 的 imread 不支持中文路径，EasyOCR 必须用 PIL 读图转 numpy 绕过
- 维基文库返回的是繁体，国学网是简体——书籍内存在简繁混用，如需统一需后续处理
